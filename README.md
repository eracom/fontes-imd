# Fontes typographiques IMD 

En avril 2021, une réflexion a été lancée en filière GR concernant la gestion de la typothèque Eracom. Historique : Un contrat daté de 2013 donnait accès aux catalogues de Monotype, Linotype et ITC, via l’outil de gestion FontExplorer. Nous devons décider si nous souhaitons reconduire un contrat similaire avec Monotype, pour avoir accès à ce catalogue. 

Les avantages / désavantages de l’offre Monotype. 

### Avantages

- Accès à des fontes “classiques” du design (orienté print). 
- Des milliers de fontes disponibles.

### Désavantages

- Les fontes sont installées via la “Monotype Desktop App” par syncronisation “cloud” (pas d’accès direct aux fichiers). 
- “Trop de choix tue le choix” : avoir accès à des milliers de fontes n’aide pas à faire les bons choix. 
- Orienté “fontes classiques” venant de la tradition du print, peu de fonderies actuelles (comparé à l’offre Adobe Fonts p.ex.). 
- Cette offre ne semble pas permettre une utilisation pour le web.

Cette offre n'apparaît donc pas comme la solution idéale pour les besoins de la filière ID.  

Voici des pistes alternatives: 

## Contre-proposition pour la filière ID

### Catalogue de fontes libres

Faire une sélection de “fontes de travail” parmi les librairies de fontes open-source, sélectionnées par les enseignant-es. Elle comportera quelques dizaines fontes libres de qualité professionnelle et validées pour des usages web et print (telles que IBM Plex, Cooper Hewitt, Source Pro...). 

Ces fontes constitueront un “canon” connu et maîtrisé par les élèves, qui devront également connaître les “fontes classiques” auxquelles les créations modernes font souvent référence (les Helvetica, Garamond, Futura, DIN etc). 

Avantage: ces fontes pourront être utilisées pour des projets web, installées sur les ordinateurs des élèves, ajoutées dans des dépôts Github, etc. 

### En complément: Trial fonts

Pour des projets précis, il est possible de travailler avec des “trial fonts” fournies par différentes fonderies contemporaines. Par exemple:  

- Grilli Type - https://www.grillitype.com/free-trial-fonts 
- Swiss Typefaces - https://www.swisstypefaces.com/support/trial-fonts/ 
- Klim Type Foundry - https://klim.co.nz/test-fonts/ 
- Dinamo Typefaces - https://abcdinamo.com/form/request-trial-fonts 
- Lineto - https://lineto.com/typefaces  
- Dalton Maag - https://www.daltonmaag.com/library  
- Fontshare (Indian Type Foundry) - https://www.fontshare.com/  

Ces fonderies proposent des “trial fonts” gratuites, pouvant être utilisée pour des maquettes en école. Pour ces fontes soumises au copyright classique, les licences ne permettent pas de les distribuer directement aux élèves. Chaque élève devra faire la demande pour avoir accès aux fontes "trial".  

L’élève devra prendre connaissance des conditions de la licence, et du coût de ces fontes (p.ex. produire un devis réaliste pour son projet de design, incluant le prix des fontes en fonction des variantes utilisées).

### Les avantages de cette approche : 

- Limiter les choix pour mieux stimuler la créativité. 
- Faire connaître des fonderies contemporaines. 
- Donner davantage de contexte aux fontes utilisées
