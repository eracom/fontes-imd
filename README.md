### Catalogue de fontes libres

Ce micro-site propose un catalogue de fontes **libres et open-source** utiles pour le web et les interfaces écran. Elles sont choisies pour leur pertinence pour des réalisations professionnelles. 

Toutes ces fontes étant sous licence libre, elles peuvent être utilisés pour des projets web, installées sur les ordinateurs des élèves, ajoutées dans des dépôts GitHub publics, etc.
